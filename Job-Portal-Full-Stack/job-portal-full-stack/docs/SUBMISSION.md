# Project Submission

## Title
Job Portal - Full Stack Web Application

## Objective
Develop a responsive web platform that allows candidates to discover and apply for jobs while recruiters manage job postings.

## Modules
1. Authentication
2. Job Search
3. Job Details
4. Job CRUD
5. Applications
6. Candidate Dashboard
7. Validation and Error Handling
8. MongoDB Database

## Expected Outcome
A working full-stack job portal demonstrating frontend development, REST API integration, database operations, authentication, CRUD operations, search, validation, and testing.

## Suggested Screenshots
- Home page with job listings
- Search results
- Login/Register
- Job details
- Candidate dashboard
- Recruiter job creation
- Recruiter job list
- MongoDB collections
- Backend health endpoint

## Conclusion
The project provides an end-to-end example of full-stack development with a practical recruitment workflow.
